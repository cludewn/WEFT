# リンクプレビュー

[ホーム](Home-ja) · [コマンド一覧](Command-Reference-ja) · [トラブルシューティング](Troubleshooting-ja) · [English](Link-Previews)

同じサーバーの対応するDiscordメッセージリンクが投稿されると、WEFTはリンク先の内容、または閲覧用ボタンを表示できます。利用者がすぐにチャンネルを移動せず、参照された議論を確認するための機能です。

**投稿元チャンネル**は、リンクが投稿され、WEFTが返信する場所です。**リンク先の対象**は、参照された元のメッセージと、そのチャンネル・スレッドを指します。サーバー管理者がモードを設定し、WEFTがその設定と、そのモードで必要な現在のアクセス・年齢条件から各リンクの表示方法を決めます。閲覧者がリンクごとに自動表示とボタン表示を選ぶ方式ではありません。

<a id="visible-previews-and-buttons"></a>

## プレビューとボタンの違い

| 表示形式             | 投稿元チャンネルでの表示                             | 閲覧・確認方法                                                                                                         |
| -------------------- | ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 自動の埋め込み       | 投稿元チャンネルの閲覧者に内容のコピーを表示します。 | WEFTの返信内のコピーを読みます。「元のメッセージを開く」ボタンはありません。                                           |
| 汎用プレビューボタン | ボタンだけを表示し、保護された内容は表示しません。   | クリックすると現在のアクセスを確認し、許可されたプレビューを本人だけに表示します。「元のメッセージを開く」が付きます。 |
| 表示なし             | WEFTのプレビュー・ボタンは表示しません。             | 以下のモード・対応リンク・アクセス条件を確認します。                                                                   |

ボタンはリンク先の存在や閲覧可能性の証明ではありません。保護された名前・著者・内容は表示しません。取得不能・権限不足などのクリック失敗は共通の汎用エラーとなり、対象の存在を明かしません。

**公開済みプレビューはその時点のコピーです。** 後から編集・削除・権限変更しても更新・削除しません。モードを選ぶ前に、自動コピーが適切か判断してください。button-onlyでも、閲覧・コピー済みの内容を取り消すことはできません。

<a id="choose-a-mode"></a>

## モードを設定してリンクを確認する

モードは**Discordサーバー全体**に適用されます。設定・確認には「サーバーの管理」権限が必要です。利用者は、リンク先への現在のアクセスに応じてプレビューボタンを使います。ボタンによって閲覧権限が付与されることはありません。

新しいリンクへの応答方法を選びます。

| `value`で選ぶ項目                             | 公開閲覧を確認できる対象 | 制限あり・未確認の対象 | 年齢制限を確認した対象 |
| --------------------------------------------- | ------------------------ | ---------------------- | ---------------------- |
| 自動表示＋プレビューボタン（`hybrid`、既定）  | 埋め込みを自動表示       | 汎用プレビューボタン   | 表示なし               |
| 公開メッセージの自動表示のみ（`public-only`） | 埋め込みを自動表示       | 表示なし               | 表示なし               |
| プレビューボタンのみ（`button-only`）         | 汎用ボタン               | 汎用ボタン             | 対象を調べず汎用ボタン |
| オフ（`off`）                                 | 表示なし                 | 表示なし               | 表示なし               |

利用者ごとにプレビューを要求してもらう設定の例です。

1. [`/config link-preview mode`](Commands-Config-ja#config-link-preview-mode)を選びます。`value`で**「プレビューボタンのみ」**（値: `button-only`）を選び、実行します。自由入力ではなく、表示された選択肢を使います。
2. 保存済み・変更なしの応答を読み、[`/config link-preview show`](Commands-Config-ja#config-link-preview-show)を引数なしで実行して保存値を確認します。
3. Discordの**「メッセージリンクをコピー」**で取得したリンクを、同じサーバーの対応チャンネルへ通常の利用者投稿として新しく投稿します。上の表と表示を照合します。ボット・Webhook・システム投稿は検出の対象外です。
4. プレビューボタンが表示されたらクリックします。許可された結果は本人だけに表示され、**「元のメッセージを開く」**が付きます。汎用エラーから対象の存在や取得できなかった理由は判断できません。

検出にはDeveloper PortalのMessage Content Intentの有効化と、WEFTの投稿元チャンネルに対する閲覧・送信・埋め込み権限が必要です。何も表示されない場合は、この前提条件、保存モード、[対応リンク](#use-a-message-link)を確認し、[プレビューの調査手順](Troubleshooting-ja#previews)へ進んでください。

`button-only`はクリックまで対象の存在・権限・年齢を調べません。`off`は対象への要求も出力も行いません。現在のモードが`off`・`public-only`なら既存ボタンも失敗します。**モード変更で過去のコピーは削除しません。** 自動表示がボタンや表示なしになる条件は[アクセスと年齢制限の確認](#access-privacy-and-copies)で説明します。

<a id="use-a-message-link"></a>

## 対応リンクと表示上限

HTTPSの`discord.com`・`discordapp.com`と、`www`・`ptb`・`canary`付きホストに対応します。パスは`/channels/<server-id>/<channel-id>/<message-id>`です。他サーバーとDMは無視します。通常URL、山括弧、Markdownのリンク先を認識し、同じ対象は重複排除します。

不正なパス、余分なパス、末尾スラッシュ、バックスラッシュ、ドットによるパス要素、明示ポート、認証情報、符号化されたIDは拒否します。IDはuint64範囲内・最大20桁・先頭0なしの正の10進数です。クエリ・フラグメントは対象の識別を変えません。

- 最大6件の異なる候補を調べ、1つの返信に最大3件のプレビュー・ボタンを表示します。
- `public-only`では制限あり・未確認・年齢条件外・取得不能の対象は表示枠を使いません。`hybrid`では汎用ボタンも枠を使いますが、年齢制限を確認した対象は使いません。
- 「プレビューN」は、省略・自動表示を含む元のリンク順です。異なる対応リンクが1件なら「プレビュー」です。ボタンは全埋め込みの後に並びます。
- 「ほかN件」は、調査済みの表示可能な省略分と6件を超えた未調査リンクの合計です。調査済みでも方針により対象外となる分は含みません。未調査分は存在・アクセスの確認ではなく、件数だけの返信になる場合もあります。`off`は件数も出しません。

<a id="access-privacy-and-copies"></a>

## アクセスと年齢制限の確認

自動表示には、一般の利用者が閲覧でき履歴も読めることを、直前の情報で確実に確認する必要があります。WEFTが読めるだけでは不十分で、非公開スレッドを自動表示しません。

公開判定では、新たに取得した`@everyone`ロールと、対象・直接の親の権限上書きを確認します。全員の「チャンネルを見る」「メッセージ履歴を読む」が残り、他のロール・メンバーの上書きでどちらも拒否されていない必要があります。情報不足・未確認では公開と判断しません。カテゴリの上書きは重ねて適用しません。この慎重な判定により、特定の閲覧者には読める場合もボタンになることがあります。

クリックでは利用者の現在の権限とWEFTのアクセスを別々に確認します。非公開スレッドでは、利用者の現在の参加または実効的な「スレッドの管理」も必要です。リンク先がアーカイブ済み・ロック中でも、参加・アーカイブ解除・ロック解除せずに読めます。

対象、またはスレッドの直接の親で、年齢制限なしと明示されている必要があります。年齢情報が不明なら表示しません。所有者・Administrator・スレッド管理・参加者でも例外はありません。出力直前にアクセスと年齢を再確認しますが、Discordの読取と送信は同時にはできません。

<a id="preview-content"></a>

## 成功したプレビューの表示内容

許可されたプレビューには、上限付きの本文、著者・アバター、場所、日時、最大1件の非ネタバレ画像添付を表示します。本文のネタバレ部分を省略し、メンションを抑止します。その他の添付、元の埋め込み、スタンプ、投票、音声、コンポーネント、転送スナップショットは省略します。返信先を追加取得しません。対応内容がない空のメッセージには汎用表示を使い、画像だけなら補足文は不要です。

WEFTは埋め込みを生成し、ネイティブ転送やなりすましWebhookは使いません。プレビュー実行・クリックの専用永続履歴や監査はなく、モード変更は監査対象です。

<a id="source-thread-and-language-behavior"></a>

## 投稿元スレッドと言語

アーカイブ済み・ロック中の投稿元には返信せず、明示的な参加・退出・アーカイブ解除・ロック解除も行いません。開いている公開・アナウンス・フォーラム投稿への通常送信で、DiscordがWEFTを参加者へ追加する場合はあります。非公開の投稿元は、スレッド管理・AdministratorがあってもWEFTの既存参加が必要です。投稿元メッセージがなくなっても、返信先のない別投稿に切り替えません。

最初のボタンは取得済みの投稿元サーバーの言語を使い、未対応時は英語です。各クリックの応答と「元のメッセージを開く」はその操作の言語に従い、`ja`のみ日本語、その他は英語です。言語変更や再起動で既存ラベルは変わらないため、新しい返信で確認してください。

問題は[トラブルシューティング](Troubleshooting-ja#previews)、設定コマンドは[`mode`](Commands-Config-ja#config-link-preview-mode)と[`show`](Commands-Config-ja#config-link-preview-show)を参照してください。
