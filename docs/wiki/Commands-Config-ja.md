# 設定コマンドの詳細

[ホーム](Home-ja) · [コマンド一覧](Command-Reference-ja) · [トラブルシューティング](Troubleshooting-ja) · [English](Commands-Config)

設定コマンドの引数と結果を調べるためのページです。現在の設定を確認する場合は、[`/config show`](#config-show)から始めてください。初めて機能を設定する場合は、表の機能ガイドに沿って進めます。

14操作すべてに、このサーバーの「サーバーの管理」権限（`ManageGuild`）が必要で、サーバー内でのみ使用できます。コマンドが表示されているだけでは実行許可になりません。操作結果とエラーは実行者だけに表示します。導入時に何を設定するかは、[サーバー設定](Configuration-ja)を参照してください。

**構文と操作方法:** 構文のコードブロックはコマンド名と引数を説明する表記で、貼り付けて実行する文字列ではありません。DiscordでWEFTのコマンド候補を選び、必須の引数を指定して実行します。引数がないコマンドでは、追加の入力は不要です。`<...>`や省略可能な引数の`[...]`は入力しません。

- **文字列:** `Asia/Tokyo`、`[DONE]`、`7d`などの値を、指定された引数に入力します。
- **文字列の選択肢:** リンクプレビューモードは、選択欄の表示名から選びます。以下の表にある値は選択肢の照合用で、自由入力する文字列ではありません。
- **チャンネル:** Discordの候補から、実際のサーバーチャンネルを選びます。例のチャンネル名を文字列として入力する操作ではありません。
- **真偽値:** ボットの投稿の扱いは、`true`または`false`を明示的に選択します。省略はできません。

選択肢の表示名はDiscordの言語で変わります。共通の入力方法は[入力・選択・フォームの使い分け](Command-Reference-ja#read-syntax)を参照してください。以下の使用例では、利用目的、指定する値、実行後の確認内容を説明します。変更が結果未確認の場合は、対応する`show`の結果を確認してから再試行してください。[結果の見方](Troubleshooting-ja#result-states)も参照してください。`show`で分かるのは現在値であり、結果未確認だった特定の要求の保存まで証明するものではありません。応答と現在値でも判断できない場合は、再変更の前に[確認できる情報](Troubleshooting-ja#available-checks)に従いホスト運用者と調べてください。

## /config show

**目的:** このサーバーのWEFTの既定タイムゾーン、クローズ用プレフィックス、監査通知先、自動クローズの概要、リンクプレビューモードを表示します。

**権限と場所:** このサーバーの「サーバーの管理」権限（`ManageGuild`）が必要です。

**構文:**

```text
/config show
```

**引数:** ありません。

**使用例:**

WEFTの設定を変更する前に、`/config show`でこのサーバーの現在の設定を確認します。新しい単発の日時指定に使う既定タイムゾーン、クローズ用プレフィックス、監査通知先、自動クローズの概要、リンクプレビューモードを確認してください。対象の親チャンネルとボットの投稿の扱いを詳しく調べる場合は、[`/config auto-close show`](#config-auto-close-show)へ進みます。

**結果:** 実行者だけに設定を表示します。無効化されたプレフィックスは「無効」と明示します。全体設定が未作成なら既定値で初期化される場合があります。

**制約:** 設定の概要であり、Discord上の送信先の存在確認や処理継続中の操作の完了確認ではありません。取得失敗は設定が空であることを意味しません。

**関連:** [サーバー設定](Configuration-ja) · [結果の見方](Troubleshooting-ja#result-states)

## /config timezone

**目的:** このサーバーのWEFTの既定タイムゾーンを変更します。

**権限と場所:** このサーバーの「サーバーの管理」権限（`ManageGuild`）が必要です。

**構文:**

```text
/config timezone value:<value>
```

**引数:**

| 引数    | 必須・任意 | 入力方法・条件                                                                                              |
| ------- | ---------- | ----------------------------------------------------------------------------------------------------------- |
| `value` | 必須       | `Asia/Tokyo`などのIANA名または`UTC`を文字列で入力します。有効な別名も使えます。数値オフセットは使えません。 |

**使用例:**

今後の単発予約で、日時を日本時間として入力したい場合の例です。

1. `/config timezone`の`value`に、文字列`Asia/Tokyo`を入力して実行します。
2. 応答でタイムゾーンの保存または変更なしを確認します。
3. 新しい日時指定を行う前に、[`/config show`](#config-show)で既定タイムゾーンが`Asia/Tokyo`になっていることを確認します。

**結果:** 保存または変更なしを表示します。以後の単発日時指定に使用します。保存済みの単発日時と定期投稿のタイムゾーンは変わりません。

**制約:** 無効なタイムゾーンは拒否します。UNCONFIRMEDなら再変更前に/config showで確認してください。Discordの日時表示や操作言語を変更する設定ではありません。

**関連:** [タイムゾーンと日時指定](Timezones-and-Scheduling-ja) · [結果の見方](Troubleshooting-ja#result-states)

## /config closed-prefix set

**目的:** 以後のクローズ時にスレッド名の先頭へ付ける文字列を設定します。

**権限と場所:** このサーバーの「サーバーの管理」権限（`ManageGuild`）が必要です。

**構文:**

```text
/config closed-prefix set value:<value>
```

**引数:**

| 引数    | 必須・任意 | 入力方法・条件                                                                            |
| ------- | ---------- | ----------------------------------------------------------------------------------------- |
| `value` | 必須       | 前後の空白を除いて1～20 Unicodeコードポイントの文字列を入力します。制御文字は使えません。 |

**使用例:**

クローズ用プレフィックスを`[DONE]`に変更する例です。

1. `/config closed-prefix set`の`value`に、文字列`[DONE]`を入力して実行します。
2. 保存または変更なしを確認し、[`/config show`](#config-show)でクローズ用プレフィックスが`[DONE]`になっていることを確認します。

このコマンドは既存のスレッド名を変更しないため、既存の名前では設定の変更を確認できません。

**結果:** 保存または変更なしを表示します。このコマンドは設定を変更し、スレッドのクローズや既存の名前の変更は行いません。今後のクローズでは新しい設定を使います。ただし、以前のクローズで保存したプレフィックスは、開いた状態がWEFTへ反映されるまで再使用します。

**制約:** 空文字や空白だけの入力は無効化ではなくエラーです。無効化にはdisableを使います。UNCONFIRMEDなら/config showで確認します。

**関連:** [スレッドのクローズと状態管理](Thread-Lifecycle-ja) · [結果の見方](Troubleshooting-ja#result-states)

## /config closed-prefix disable

**目的:** クローズ用プレフィックスの設定を無効にします。

**権限と場所:** このサーバーの「サーバーの管理」権限（`ManageGuild`）が必要です。

**構文:**

```text
/config closed-prefix disable
```

**引数:** ありません。

**使用例:**

クローズ用プレフィックスの設定を無効にするには、`/config closed-prefix disable`を実行します。無効化またはすでに無効という結果を確認し、[`/config show`](#config-show)でクローズ用プレフィックスが「無効」になっていることを確認してください。既存の名前と、WEFTの`CLOSED`記録に保存済みのプレフィックスは変わりません。

**結果:**

- **設定:** 無効化またはすでに無効を表示します。このコマンド自体はスレッドをクローズしません。既存のスレッド名と、WEFTの`CLOSED`記録に保存済みのプレフィックスは変わりません。
- **今後のクローズ:** プレフィックスを付加しません。ただし、`CLOSED`として記録されたスレッドの再クローズでは、開いた状態がWEFTへ反映されるまで、空でないものも含め保存済みプレフィックスを再使用します。

**制約:** 既存のプレフィックスは除去せず、Discordの名前変更制限を回避できる保証もありません。保存未確認なら/config showで確認します。

**関連:** [スレッドのクローズと状態管理](Thread-Lifecycle-ja) · [結果の見方](Troubleshooting-ja#result-states)

**権限と場所:** このサーバーの「サーバーの管理」権限（`ManageGuild`）が必要です。

**構文:**

```text
/config link-preview show
```

**引数:** ありません。

**使用例:**

メッセージリンクの表示方法を調べたい場合は、`/config link-preview show`を実行します。表示されたモードを[リンクプレビューのモード表](Link-Previews-ja#choose-a-mode)と照合してください。これは設定の確認であり、特定のリンクをプレビューできるかのテストではありません。

**結果:** 設定がなければ作成せず既定のhybridを表示し、設定済みならそのモードを表示します。

**制約:** 個別リンクの確認や、プレビューを送信できることの保証は行いません。取得失敗は別の結果です。

**関連:** [リンクプレビュー](Link-Previews-ja) · [結果の見方](Troubleshooting-ja#result-states)

## /config link-preview mode

**目的:** 自動表示、権限確認付きボタン、表示なしのモードを選びます。

**権限と場所:** このサーバーの「サーバーの管理」権限（`ManageGuild`）が必要です。

**構文:**

```text
/config link-preview mode value:<value>
```

**引数:**

| 引数    | 必須・任意 | 入力方法・条件                                                                                                                      |
| ------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `value` | 必須       | 文字列の選択肢からモードを選びます。対応する値は`hybrid`、`public-only`、`button-only`、`off`です。表示名は下表を参照してください。 |

Discordの`value`で次の表示名から選びます。値は照合用です。

| 日本語の表示名               | 英語の表示名                   | 値            |
| ---------------------------- | ------------------------------ | ------------- |
| 自動表示＋プレビューボタン   | Automatic previews + buttons   | `hybrid`      |
| 公開メッセージの自動表示のみ | Automatic public previews only | `public-only` |
| プレビューボタンのみ         | Preview buttons only           | `button-only` |
| オフ                         | Off                            | `off`         |

**使用例:**

自動表示を使わず、閲覧権限を確認するプレビューボタンを表示したい場合の例です。

1. `/config link-preview mode`の`value`で「プレビューボタンのみ」（値: `button-only`）を選択して実行します。
2. 応答で変更後のモードまたは変更なしを確認します。
3. [`/config link-preview show`](#config-link-preview-show)で「プレビューボタンのみ」が表示されることを確認します。

**結果:** 変更後のモードまたは変更なしを表示します。offとpublic-onlyでは既存のプレビューボタンも使用できません。

**制約:** 変更しても公開済みのコピーは削除しません。UNCONFIRMEDならshowで確認してから再試行します。年齢制限や情報公開の範囲はモード表を参照してください。

**関連:** [リンクプレビュー](Link-Previews-ja) · [結果の見方](Troubleshooting-ja#result-states)

## /config audit-log show

**目的:** Discordの監査通知先の設定を表示します。

**権限と場所:** このサーバーの「サーバーの管理」権限（`ManageGuild`）が必要です。

**構文:**

```text
/config audit-log show
```

**引数:** ありません。

**使用例:**

監査通知の保存済み送信先を調べたい場合は、`/config audit-log show`を実行します。通知が無効か、チャンネルIDが保存されているかを確認してください。IDが表示されていても通知が届かない場合は、[監査とプライバシー](Audit-and-Privacy-ja)で通知の仕組みを確認します。保存IDだけでは、現在もそのチャンネルが存在し、利用できるとは判断できません。

**結果:** 無効または保存済みチャンネルIDを表示します。削除済みチャンネルでも保存IDを表示します。設定未作成なら作成せず無効として読み取ります。

**制約:** 送信先の権限や通知の送信をテストするものではありません。通知がないことは操作が行われなかった証明にはなりません。

**関連:** [監査とプライバシー](Audit-and-Privacy-ja) · [結果の見方](Troubleshooting-ja#result-states)

## /config audit-log set

**目的:** 任意のDiscord監査通知の送信先を設定します。

**権限と場所:** このサーバーの「サーバーの管理」権限（`ManageGuild`）が必要です。

**構文:**

```text
/config audit-log set channel:<channel>
```

**引数:**

| 引数      | 必須・任意 | 入力方法・条件                                                                                          |
| --------- | ---------- | ------------------------------------------------------------------------------------------------------- |
| `channel` | 必須       | このサーバーのテキストまたはアナウンスチャンネルを選びます。WEFTにViewChannelとSendMessagesが必要です。 |

**使用例:**

既存の`#weft-audit`へ任意の監査通知を送る場合の例です。

1. 対象のテキストまたはアナウンスチャンネルで、WEFTに表示とメッセージ送信の権限があることを確認します。
2. `/config audit-log set`の`channel`で対象を選択して実行します。`#weft-audit`は例の名前です。実際の送信先を選んでください。
3. 保存または変更なしを確認し、[`/config audit-log show`](#config-audit-log-show)で保存された送信先を確認します。

応答が確認するのは設定の保存であり、テスト通知の送信ではありません。

**結果:** 現在の送信先とボット権限を確認し、保存または変更なしを表示します。設定と変更の監査記録は同時に保存します。

**制約:** スレッド、フォーラム、アクセスできない送信先は拒否します。権限確認はその時点のものです。UNCONFIRMEDならshowで確認します。テスト通知の送信や、将来も通知が届くことを保証するものではありません。

**関連:** [監査とプライバシー](Audit-and-Privacy-ja) · [結果の見方](Troubleshooting-ja#result-states)

## /config auto-close show

**目的:** 無投稿期間、ボットの投稿を含めるか、対象の親チャンネルを確認します。

**権限と場所:** このサーバーの「サーバーの管理」権限（`ManageGuild`）が必要です。

**構文:**

```text
/config auto-close show
```

**引数:** ありません。

**使用例:**

自動クローズの設定後に、`/config auto-close show`を実行します。無投稿期間、ボットの投稿を含めるか、目的の親チャンネルが有効かを確認してください。対象の親チャンネルがない場合は、[自動クローズの設定手順](Automatic-Close-ja)へ進みます。個別スレッドの対象・除外と活動記録は、「スレッドの管理」権限（`ManageThreads`）を持つ利用者が、そのスレッド内で[`/thread status`](Commands-Thread-ja#thread-status)を実行して確認します。

**結果:** 詳細なポリシーを表示します。親チャンネルが未設定なら自動クローズ候補はありません。親の表示は最大25件と残り件数で、設定可能数の上限ではありません。スレッドごとの除外設定も適用します。全体設定が未作成なら既定値で初期化される場合があります。

**制約:** 対象スレッドの全列挙や処理継続中の状態反映の確認ではありません。最初の25件に表示されない親が、無効とは限りません。その親に属するスレッド内で、「スレッドの管理」権限を使って`/thread status`を実行し、親の設定を確認してください。

**関連:** [自動クローズ](Automatic-Close-ja) · [結果の見方](Troubleshooting-ja#result-states)

## /config auto-close inactivity

**目的:** 対象スレッドを自動クローズする条件となる無投稿期間を設定します。

**権限と場所:** このサーバーの「サーバーの管理」権限（`ManageGuild`）が必要です。

**構文:**

```text
/config auto-close inactivity value:<value>
```

**引数:**

| 引数    | 必須・任意 | 入力方法・条件                                                                                                                           |
| ------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `value` | 必須       | 正の整数と単位`m`、`h`、`d`のいずれかを1組の文字列で入力します。範囲は両端を含む5分～365日です。例えば`30m`、`12h`、`7d`を指定できます。 |

**使用例:**

自動クローズの対象となる無投稿期間を7日間にする場合の例です。

1. `/config auto-close inactivity`の`value`に、文字列`7d`を入力して実行します。
2. 保存または変更なしを確認し、[`/config auto-close show`](#config-auto-close-show)で無投稿期間が`7d`になっていることを確認します。
3. 目的の親チャンネルが有効かを確認します。必要なら[`/config auto-close add-parent`](#config-auto-close-add-parent)で追加します。

期間の設定だけでは、親チャンネルは有効になりません。また、正確なクローズ時刻を指定する操作ではありません。

**結果:** 保存または変更なしを表示します。新しい期間を記録済みの活動に適用し、全スレッドの計測をリセットしません。期間を短くすると既存の活動時刻がすぐ条件を満たす場合があります。

**制約:** 複合単位や小数は使用できません。スレッド作成からの経過時間でも、正確なクローズ時刻でもありません。変更未確認ならshowで確認します。

**関連:** [自動クローズ](Automatic-Close-ja) · [結果の見方](Troubleshooting-ja#result-states)

**構文:**

```text
/config auto-close bot-messages value:<value>
```

**引数:**

| 引数    | 必須・任意 | 入力方法・条件                                                                                               |
| ------- | ---------- | ------------------------------------------------------------------------------------------------------------ |
| `value` | 必須       | 真偽値の`true`または`false`を選びます。設定の初期値は`false`ですが、このコマンドでは明示的な選択が必須です。 |

**使用例:**

WEFTを含むボットの新しい投稿を、無投稿期間の計測に含めたい場合の例です。

1. `/config auto-close bot-messages`の`value`で真偽値の`true`を選択して実行します。
2. 応答で、ボットの投稿を含める設定の保存または変更なしを確認します。
3. [`/config auto-close show`](#config-auto-close-show)で、ボットの投稿が「含める」と表示されることを確認します。

ボットの投稿で無投稿期間を延長させない場合は、`false`を選択します。以後の投稿の扱いを変更する操作であり、過去のメッセージは再集計しません。

**結果:** 含める・含めないと、保存または変更なしを表示します。有効ならWEFTを含む以後のボット投稿が活動として扱われます。

**制約:** Discordシステムメッセージは常に対象外です。リアクション、名前や設定の変更も数えません。過去の履歴を再集計する設定ではありません。UNCONFIRMEDならshowで確認します。

**関連:** [自動クローズ](Automatic-Close-ja) · [結果の見方](Troubleshooting-ja#result-states)

## /config auto-close add-parent

**目的:** 親チャンネル1件の自動クローズを有効にし、現在開いている対象スレッドの計測開始時刻を設定します。

**権限と場所:** このサーバーの「サーバーの管理」権限（`ManageGuild`）が必要です。

**構文:**

```text
/config auto-close add-parent channel:<channel>
```

**引数:**

| 引数      | 必須・任意 | 入力方法・条件                                                           |
| --------- | ---------- | ------------------------------------------------------------------------ |
| `channel` | 必須       | このサーバーのテキスト、アナウンスまたはフォーラムチャンネルを選びます。 |

**使用例:**

既存の`#support`内のスレッドで、自動クローズを有効にする場合の例です。

1. [`/config auto-close show`](#config-auto-close-show)で無投稿期間を確認し、必要なら先に変更します。
2. `/config auto-close add-parent`の`channel`で、対象のテキスト、アナウンスまたはフォーラムチャンネルを選択して実行します。`#support`は例の名前です。
3. 有効化と計測開始時刻の設定件数、またはすでに有効という結果を確認します。[`/config auto-close show`](#config-auto-close-show)で対象の親チャンネルを確認します。個別スレッドの対象・除外は、「スレッドの管理」権限（`ManageThreads`）を持つ利用者が、そのスレッド内の[`/thread status`](Commands-Thread-ja#thread-status)で確認します。

設定の成功は、スレッドのクローズが完了したことを意味しません。

**結果:** 有効化と計測開始時刻の設定件数、またはすでに有効を表示します。新しい活動時刻を保持し、除外中のスレッドには適用しません。再実行しても既存の時刻をリセットしません。

**制約:** 先にWEFTが開いているスレッドを取得します。取得失敗なら有効化しません。DB結果未確認ならshowやstatusで確認します。有効にした直後に、古いスレッドがすべてクローズされるわけではありません。

**関連:** [自動クローズ](Automatic-Close-ja) · [結果の見方](Troubleshooting-ja#result-states)

## /config auto-close remove-parent

**目的:** 設定済みの親チャンネル1件の自動クローズを無効にします。

**権限と場所:** このサーバーの「サーバーの管理」権限（`ManageGuild`）が必要です。

**構文:**

```text
/config auto-close remove-parent channel:<channel>
```

**引数:**

| 引数      | 必須・任意 | 入力方法・条件                                                                                         |
| --------- | ---------- | ------------------------------------------------------------------------------------------------------ |
| `channel` | 必須       | 自動クローズを無効にする親チャンネルを選びます。設定されていないチャンネルを選んでも変更はありません。 |

**使用例:**

`#support`内の自動クローズを止めたい場合の例です。

1. `/config auto-close remove-parent`の`channel`で、無効にする親チャンネルを選択して実行します。
2. 無効化、または未設定による変更なしを確認します。
3. [`/config auto-close show`](#config-auto-close-show)で、残っている対象の親チャンネルを確認します。最大25件の表示なので、表示にないだけでは無効化を確認できません。外した親に属するスレッド内で、「スレッドの管理」権限を使って[`/thread status`](Commands-Thread-ja#thread-status)を実行し、親の設定を確認してください。

個別の予約クローズは取り消されず、開始済みのクローズも取り消しません。

**結果:** 無効化または未設定による変更なしを表示します。活動記録と個別除外を保持します。明示的な予約クローズは独立して残ります。

**制約:** スレッドを再開せず、開始済みのクローズを取り消しません。再度有効にすると、その時点から無投稿期間を計測します。より新しい活動記録は保持します。UNCONFIRMEDならshowで確認します。

**関連:** [自動クローズ](Automatic-Close-ja) · [結果の見方](Troubleshooting-ja#result-states)
